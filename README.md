# Study Tutor Skill 📚

A highly capable Study Tutor AI agent skill that transforms passive lecture notes, slides, and academic files into active-recall study assets. Built to integrate directly with your AI agent workflow, this skill automatically reads academic materials and generates interactive, polished HTML study guides.

## ✨ Features

Passive reading has near-zero retention. This skill forces active recall by generating:
* **Smart Extraction:** Automatically ingests and parses `.pdf`, `.pptx`, `.xlsx`, `.docx`, and code files.
* **Active Recall Flashcards:** Generates interactive flip-cards tagged by difficulty (🟢 Basic, 🟡 Intermediate, 🔴 Advanced).
* **Feynman Explanations:** Breaks down the hardest concepts into simple, intuitive explanations.
* **Knowledge Graphs:** Builds visual, Zettelkasten-style connection maps to link concepts together.
* **Tiered Exercises:** Creates recall, application, and synthesis practice problems with hidden solutions.
* **Ready-to-Use UI:** Outputs a beautiful, mobile-responsive HTML study guide complete with dark mode, sidebar navigation, and syntax highlighting.
